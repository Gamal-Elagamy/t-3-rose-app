# Rose App

Rose App is a training e-commerce project developed by Team 3 as part of the Elevate Front-End Bootcamp. The project aims to simulate a real-world online shopping experience while applying modern front-end development practices and team collaboration workflows.

## Features

- Multi-language support (English & Arabic) using Next-Intl
- Dark Mode & Light Mode support
- Product browsing and shopping experience
- Form handling and validation
- Scalable and maintainable project architecture
- Team-based development workflow using GitHub, Pull Requests, and Code Reviews

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- Next-Intl
- TanStack React Query
- React Hook Form
- Zod
- ESLint
- Prettier
- Husky
- lint-staged

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## Available Languages

- English (/en)
- Arabic (/ar)
